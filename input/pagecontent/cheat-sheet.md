### Cheat Sheet

A one-page lookup of where every important concept lives in the IG. For prose explanations and full snippets see the per-artifact pages: [Guideline](authoring-guideline.html), [Registry Record](authoring-registry-record.html), [Recommendation](authoring-recommendation.html), [Justification](authoring-justification.html).

**Conventions in the tables below**

- `EBM` = `https://fevir.net/resources/CodeSystem/179423` (the EBM-IG code system shared with the FHIR EBM IG)
- `AWMF-CS` = `http://fhir.awmf.org/awmf.ig/CodeSystem/cs-awmf`
- `AWMF` (as URL prefix) = `http://fhir.awmf.org/awmf.ig/StructureDefinition/` (extension URLs)
- All profile canonical URLs start with `http://fhir.awmf.org/awmf.ig/StructureDefinition/`
